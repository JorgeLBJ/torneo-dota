# Feature: promo-banners
Per-tournament welcome banners: an image shown as a dialog when the public page opens, scheduled by dates, with a configurable button that jumps to a tab.
Branch: feat/promo-banners · Delivery: ask-on-risk · Runner: `npx vitest run` + `npm run typecheck` (+ `node --check` for public/*.js)

## Specs
- S1 Admin screen "Banners" per tournament (user: "por torneo"), in the tournament sidebar section. Approved mockup: `Desktop/mockup-banners/index.html`.
- S2 Upload an image (user: "se suba una imagen"); several banners per tournament (user: "por si tengo varias imagenes"). Accept JPG/PNG/WebP up to 10 MB, validated by decoding like team images.
- S3 Optimize before uploading to R2 (user: "optimizar la imagen siempre que se cargue antes de subir a r2 sin perder casi calidad"): WebP quality 82, two widths 1920 px and 1280 px (no enlargement, keep aspect ratio, no crop), metadata stripped; served with srcset. Measured on the real final banner: 3539 KB PNG -> 374 KB (1920) / ~210 KB (1280).
- S4 Enable whenever the admin wants (user: "que se habilite cuando yo quiera ... y se ponga activo"): an "Activo" switch per banner.
- S5 Dates (user: "controlar que fechas saldrá sin que se pisen con más configuraciones"): optional "Mostrar desde" / "Hasta" in the tournament time zone, stored UTC. Saving an ACTIVE banner whose window overlaps another ACTIVE banner of the same tournament is rejected with a Spanish error naming the other banner. No dates = open-ended (overlaps everything active). Inactive banners never conflict.
- S6 Button (user: "que redirija a alguno de los tabs, por ejemplo ... redirija el CTA al playoffs"; "tal vez el texto configurable y la redireccion entre las pestañas que tenemos un selector"): configurable button text (example "Ver playoffs") and a selector: Solo cerrar, Partidos, En vivo, Posiciones, Playoffs, Reglas. Clicking it closes the dialog and switches to that tab.
- S7 Public page: when a banner is active and within its window ("now"), open it as a modal dialog on load (approved preview: centered, dimmed blurred backdrop, close via ×, button, click outside, Esc; respects reduced motion). Shown once per visit (sessionStorage keyed by banner id + version); a different/updated banner shows again. Never block first render: dialog opens after load.
- S8 States in the admin list: Mostrándose ahora / Programado / Terminado / Inactivo; alt text field; delete banner (removes stored images).
